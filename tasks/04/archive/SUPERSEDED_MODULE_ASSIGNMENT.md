# 任务 4：五路执行、正式清单与复现

分支：`task-4-parallel-reproducibility`。预计 **14 小时**，个人预留 12–16 小时；机器排队和后台运行另计。

## 从哪里开始

先运行 python -m unittest discover -s tests -v，再 inspect 五份 MVP 清单；理解预算份额、未知费用停止和不覆盖已有目录的约束。

## 工时安排

- 正式清单与可审计续跑：4 小时。
- 单路和五路吞吐测量：3 小时。
- 环境与 PBS 调度：3 小时。
- 集成和故障验证：4 小时。

## 负责文件

trustgate/、scripts/、experiments/mvp/run_matrix_v2.py 的集成、依赖和公共运行文档、tests/test_task4_*。自己的 `tasks/04/` 可自由补充。共同接口见 [接口说明](../../../docs/INTERFACES_ZH.md)。

## 交付物

冻结后 1,680 个案例的清单适配；五路作业和汇总；显式续跑/基础设施故障记录；1 路与 5 路实际吞吐对比；复现说明。

## 验收清单

- [ ] 新正式清单等于 420 正常 + 1,260 攻击，ID 唯一、分片不重复。
- [ ] 每个 worker 有独立 MCP 后端状态、日志和输出；模型缓存只读。
- [ ] 总预算不能在五路各自重复使用，未知收费请求不可自动重发。
- [ ] 续跑只补明确未开始的案例，失败任务保留，不能重写历史结果。
- [ ] 校验来源 commit 和清单哈希，汇总必须检测重复、漏项和版本混用。
- [ ] 所有代码与测试在计算节点执行，记录真实结果和剩余局限。
- [ ] PR 写明影响的接口、验证命令和实际人工工时；完成后由组员审核合并。

## 合作方式

所有人从共同 main 基础开发。正式接口由任务 4 集成；任务 5 可先用历史数据工作。初始化提交仅提供任务材料，不代表此任务已完成。
