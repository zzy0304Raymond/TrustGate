# 任务 5：指标、统计、报告与演示

分支：`task-5-evaluation-report`。预计 **14 小时**，个人预留 12–16 小时；机器排队和后台运行另计。

## 从哪里开始

从 results/pilot/all_runs.csv 和 followup_runs.csv 分别计算基础指标；先复现报告中的原始 81 次结果，不能把 21 次开发复测合并。

## 工时安排

- 配对指标和不确定性分析：4 小时。
- 答案与状态人工抽查：3 小时。
- 图表与研究报告：4 小时。
- 演示与真实贡献记录：3 小时。

## 负责文件

analysis/、reports/、docs/evaluation/、tests/test_task5_*。自己的 `tasks/05/` 可自由补充。共同接口见 [接口说明](../../../docs/INTERFACES_ZH.md)。

## 交付物

按入口/业务/配置分别统计的结果；任务配对或按任务分组的区间；误报、效用、安全完成、延迟和成本图表；最终报告和可复现演示。

## 验收清单

- [ ] 攻击成功率、正常效用和安全完成分别报告，不只看攻击成功率。
- [ ] 明确计划数、已运行数、到达注入点数以及错误和超时。
- [ ] 任务级配对；同一 payload 的三次重复不当成三个独立攻击。
- [ ] API usage.cost 与额度余额区分，吞吐时间与每任务耗时区分。
- [ ] 成员真实贡献占比最终合计 100%；未完成时留空，不用预计工时编造成实际贡献。
- [ ] 所有代码与测试在计算节点执行，记录真实结果和剩余局限。
- [ ] PR 写明影响的接口、验证命令和实际人工工时；完成后由组员审核合并。

## 合作方式

所有人从共同 main 基础开发。正式接口由任务 4 集成；任务 5 可先用历史数据工作。初始化提交仅提供任务材料，不代表此任务已完成。
